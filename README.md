**Stellar Gallery**

Stellar Gallery is a space-themed image gallery that uses NASA's Astronomy Picture of the Day (APOD) API to display images from space. Users can explore different astronomy images, view the description of each image, and save their favorites.

**Technologies Used**
HTML
CSS
JavaScript
NASA APOD API

**Current Progress**

The main gallery page has been styled and improved with a cleaner layout and design. The favorites page is still being worked on, with some issues remaining around displaying saved images.
